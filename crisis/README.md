# 古巴导弹危机：八章决定

肯尼迪视角，1962年10月16日至11月。八章依次处理发现导弹、应对办法、船只接触或外交期限、不入侵保证、侦察机被击落、土耳其导弹、撤除答复以及古巴核查争议。

每章都明确写出事件、日期、要处理的问题、足够的背景、仍不知道的事情与美国可以作出的完整决定。选择海上隔离与选择外交等待的下一章内容分别处理；苏联未接受撤除时，不会自动宣布10月28日历史安排已经达成。军事攻击分支在本版覆盖范围结束后停止，允许分析已经完成的决定。

## 页面与存档

纯静态网页；GitHub Pages入口为`index.html`。加载`style.css`、`engine.js`、`scenario-v2.js`与`app-v2.js`。不连接AI，无密钥、无服务器依赖。

正常游戏只展示事件、完整选项与各方回应。终局分析按钮在本局结束前禁用；回到先前章节重选，会重新锁定。行动记录不展示逐步模型分析。新存档键`cuban-crisis-clear-v2`与旧版隔离；恢复时根据选择重新计算，不信任存档中的模型输出。

## 核心模型

独立实现GMCR序数冲突图。五个条件分别为：

|代码|条件|
|---|---|
|U1|美国维持本轮谈判中的军事施压条件。|
|U2|美国提出不入侵古巴的保证。|
|S1|苏联接受拆除并运走部署在古巴的有关导弹。|
|C1|古巴接受有关人员进入古巴实施现场核查。|
|C2|古巴愿意参加导弹撤除与核实办法的有关磋商。|

1表示成立，0表示不成立。页面每行同时写明本局值与完整含义，并解释状态数字的排列顺序。S1成立不表示武器已经撤离；C1成立不表示检查已经完成。初始C2为情境预设。通常32个组合，过滤“拒绝磋商但接受核查”后24个。

美国只能改变U1/U2。其他方面各自改变自己的条件。国家排序为作者设定，未作实证估计。其他方按固定顺序各至多行动两轮，只选自身严格改善的动作，优先考虑不易被其他方自身有利回应挡回的动作。这是附加游戏规则，不是GMCR唯一预测。核查程序比较情境切换古方排序，不预测真实古巴必然接受。

终局统一显示Nash、SEQ、GMR、SMR，逐项解释判据、0/1及行动数量；列出由当前状态实际算出的行动和回应示例。路径最多搜索五步，每步要求符合行动方排序，不能当作必然路线。MID单独分类事件，非等距分数、非核战概率。

土耳其导弹、秘密与公开承诺、盟友和国家内部行动者尚未完整进入五条件模型，剧情记录与核心计算明确区分。模型没有计算每枚武器的拆除、运输和核实过程，也不自动宣布解除海上隔离。完整来源见网页“史料说明”。
