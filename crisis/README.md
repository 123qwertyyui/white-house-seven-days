# 危机前后

肯尼迪视角的历史决策模拟，1961—1963。4 章、18 个节点，包含柏林、核试验争议、古巴导弹危机以及危机后的核查、通信与有限禁试。

纯静态网页，无构建依赖、无服务端、无 AI API。用普通 HTTP 服务打开 `index.html`；适合 GitHub Pages。浏览器只保存本机进度，可以下载 JSON 行动记录。离线下载整个目录也可运行，不依赖外部字体或脚本。

## 运行模型

`engine.js` 独立实现序数冲突图、Nash / GMR / SEQ / SMR 稳定性与路径搜索。每方只能改变自己控制的条件。每阶段 5 个二元条件，32 个组合；古巴模型过滤为 24 个可行状态。偏好用字典序排列，非国家实力或核战概率。

行动生成另加确定性规则：非美方按固定顺序各至多行动两轮，只选择自身严格改善的动作；先考虑不易受其他方有利反制的动作，再按偏好排序择优；同序按状态编号。此规则不是 GMCR 唯一解，也不是完整的不完全信息均衡。

情境偏好是作者设定，未做系统史料估计。改变核查程序可切换古方排序，属于敏感性情境，不是预测真实卡斯特罗必然接受。军事分支只记录进入武力的路径，不虚构战争结果。国际共同文本、国内批准和完成执行分别处理。非国家行为体目前没有完整独立决策模型。

`scenario.js` 保存简报、选项、历史对照、史料出处和场景变换。运行时的回复不是历史原话。后台完整模型只在复盘展开。

## 复现与验证

执行 `node test.cjs`。覆盖 Kato 四状态算例、权限与可行性、稳定性关系、行动与路径有效性、核查假设变化、完整 18 节点、军事分支与重选、存档重建、250 条固定种子分支。

Kato 状态映射：0=CC，1=DC，2=CD，3=DD（先美后苏）。美国偏好 CC>DC>DD>CD；苏联 CC>CD>DD>DC。原图全体 Nash/SEQ 稳定为 CC、DD；加入论文讨论的 DD→CC 特殊边后为 CC。这条边只存在于检验小算例，不能理解为普通苏方行动有权更改美国决定。Kato 小算例检验实现，不检验历史预测能力。

MID 按公开类别定义作项目内编码，类别有序而非等距；历史峰值不回落。封锁类海上隔离记为使用武力；授权规则不等同已发生的行动。未使用逐日历史核战概率或经过估计的危机指数。
